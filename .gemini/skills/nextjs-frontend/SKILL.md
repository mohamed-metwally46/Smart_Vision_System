# Next.js Frontend Skill

Expertise in building high-performance monitoring dashboards with Next.js and TailwindCSS.

## Expertise
- **Next.js**: App Router, Server Components, and client-side optimization.
- **Real-time UI**: Visualizing live camera streams and dynamic alert notifications.
- **Data Visualization**: Heatmaps and analytics charts (Recharts/Chart.js).
- **State Management**: React Context or Zustand for global application state.

## Guidelines
- **Performance**: Minimize re-renders in pages with live video feeds.
- **UX/UI**: Ensure visual clarity for security alerts and intuitive navigation.
- **Responsiveness**: Dashboard must be accessible across various screen sizes.
- **Integration**: Seamless connection with FastAPI WebSockets for live data.

## Reference Components
- Camera Monitoring Grid
- Real-time Alert Sidebar
- Analytics Heatmap View

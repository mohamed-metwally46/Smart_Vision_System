# AI Vision Skill

Expertise in real-time computer vision using YOLOv8, OpenCV, and ByteTrack.

## Expertise
- **YOLOv8**: Training, fine-tuning, and optimized inference for object detection (people, weapons).
- **ByteTrack**: Multi-object tracking integration for identity persistence across frames.
- **OpenVINO/ONNX**: Model optimization for edge deployment.
- **Performance**: High-FPS stream processing and efficient memory management.

## Guidelines
- **Modularity**: Separate detection, tracking, and annotation into distinct classes.
- **Scalability**: Support multiple camera streams using threading or multiprocessing.
- **Accuracy**: Implement confidence thresholds and Non-Maximum Suppression (NMS) properly.
- **Project Specifics**: Adhere to the `Smart Vision System` architecture for real-time alerts.

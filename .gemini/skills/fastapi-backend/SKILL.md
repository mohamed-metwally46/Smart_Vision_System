# FastAPI Backend Skill

Expertise in building scalable, real-time backends with FastAPI, WebSockets, and Celery.

## Expertise
- **FastAPI**: RESTful API design, Pydantic validation, and dependency injection.
- **WebSockets**: Real-time event broadcasting and multi-client state management.
- **Celery**: Background task processing for heavy AI inference and logging.
- **PostgreSQL/SQLAlchemy**: Efficient database schema design for surveillance logs.

## Guidelines
- **Clean Architecture**: Maintain separation between API routes, services, and models.
- **Security**: Implement JWT authentication and secure WebSocket connections.
- **Efficiency**: Use asynchronous programming (`async/await`) wherever possible.
- **Reliability**: Implement robust error handling and logging for camera worker processes.
